## 🚀 Requisitos de Instalación
1. Servidor web local (XAMPP / WAMP / Laragon) con **PHP 8.0+** y **MySQL / MariaDB**.
2. Clonar el repositorio en la carpeta pública del servidor (`htdocs`):
   git clone https://github.com/NillsBG/Sistema_de_gestion_de_tutorías_y_asesorias_academicas_Grupo6.git
3. Importar el archivo `schema.sql` en phpMyAdmin o MySQL Workbench para crear la base de datos `tutoria_umg`.
